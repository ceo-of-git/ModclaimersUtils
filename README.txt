A basic yet heavily configurable mod made to help with an idea for a minecraft smp 
world where only certain players have access to certain mods, and kill eachother with these mods

*bolded features are implemented*
Planned Features:
- Configurable feature to block certain player Usernames or UUIDs from interacting with certain mods.
  - Blocks will still be breakable, but picked up items will immediately be dropped.

- Configurable feature to block certain player Usernames or UUIDs from entering a specific region of the world
  - Of which can be dropped with a command.
  
- Togglable Hardcore mode deaths that lock the player into spectator mode
  - Additional option to make your killer obtain the permissions to use your mods

- Custom Loot Crate block for Aura
  - Along with some other Admin-Only building blocks

... and more things that I haven't thought of yet
